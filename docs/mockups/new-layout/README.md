# New layout mock-up (Nov 2026)

A picture of the proposed layout from James's "making it better" list, for James to approve before anything in `src/app/` changes. Not part of the app or the build. All names, jobs and numbers are made up.

- Live, clickable version (James's claude.ai account): https://claude.ai/artifact/AjAU5NUEiNY8WX7bDMDt4Z
- Five sections instead of 26 tabs: Today, Jobs & clients, People, Paperwork, Setup. Bottom bar on a phone, left-hand menu on a computer or iPad. A "+" quick-add button on every screen.
- `Map.dc.html` lists where each of today's tabs goes.

The files are Design canvas artboards (`*.dc.html` + `canvas.json`): plain HTML with inline styles, readable as a reference for colours, spacing and sizes. Colours and fonts match `src/styles/base.css` (brand `#7F191D`, Oswald headings, Barlow body).
